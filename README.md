# Reproducibility files: norm-dependent finite-budget layer allocation

This repository contains the code and numerical data supporting the manuscript:

**Norm-Dependent Finite-Budget Layer Allocation on Shishkin and Bakhvalov-S Meshes for Singularly Perturbed Reaction-Diffusion Problems**

Author: **Ajay Singh Rathore**, School of Management, IILM University, Gurugram, India.

## Contents

- `core.py` - numerical kernels, mesh generators, exact manufactured solutions, finite-difference solver, error metrics, and frozen-layer functions.
- `reproduce_jsc_stype.py` - deterministic driver that regenerates the numerical sweeps, summary statistics, manuscript data, and figures.
- `data/` - numerical data supporting the manuscript tables and reported validation checks. Compact files are included for direct inspection; the complete source sweeps are regenerated by the driver into `output/data/`.
- `summary.json` - compact summary of the principal numerical checks.
- `REPRODUCIBILITY_CHECKS.md` - audit notes and independently checked numerical values.
- `requirements.txt` - Python dependencies.
- `CITATION.cff` - citation metadata for this repository.

## Python environment

Designed for Python 3.10+. The final reproducibility audit was run with Python 3.13.5, NumPy 2.3.5, pandas 2.2.3, and Matplotlib 3.10.8.

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Reproduction

Run from the repository root:

```bash
python reproduce_jsc_stype.py
```

By default, regenerated CSV files and figures are written to `output/`. To choose another directory, use `--out`, for example:

```bash
python reproduce_jsc_stype.py --out results
```

The driver uses deterministic parameter sweeps and a fixed random seed for the random frozen-layer validation. It regenerates the source datasets for:

1. balanced single-layer asymptotics;
2. maximum-norm and balanced-norm allocation crossover on Shishkin meshes;
3. exhaustive finite-budget Shishkin optima;
4. the 800-case frozen balanced-objective validation;
5. Bakhvalov-S crossover and exhaustive optima;
6. parameter-uniform maximum-norm pilot calculations;
7. resolution-threshold sensitivity;
8. Bakhvalov-S pure-layer coefficient checks.

The repository also records a small deterministic Pareto diagnostic used during the allocation analysis; it is supplementary to the main manuscript results.

## Data availability

The numerical data supporting the reported tables and figures are included under `data/`. The supplied deterministic Python code regenerates the full numerical sweeps and figure files from scratch, so no external or proprietary dataset is required.

## Software

The computations use NumPy, pandas, and Matplotlib. No proprietary software is required.
