# Reproducibility files: norm-dependent finite-budget layer allocation

This repository contains the code and numerical data supporting the manuscript:

**Norm-Dependent Finite-Budget Layer Allocation on Shishkin and Bakhvalov-S Meshes for Singularly Perturbed Reaction-Diffusion Problems**

Author: **Ajay Singh Rathore**, School of Management, IILM University, Gurugram, India.

## Contents

- `reproduce_jsc_stype.py` — reproduces the numerical experiments, tables, summary statistics, and figures used in the manuscript.
- `data/` — CSV files generated by the reproducibility workflow and used for the reported numerical comparisons.
- `summary.json` — compact summary of the principal numerical checks.
- `requirements.txt` — Python dependencies.

## Python environment

Designed for Python 3.10+. The final reproducibility audit was run with Python 3.13.5, NumPy 2.3.5, pandas 2.2.3, and Matplotlib 3.10.8.

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Reproduction

Run:

```bash
python reproduce_jsc_stype.py
```

By default, regenerated CSV files and figures are written to `output/`. To choose another directory, use `--out`, for example:

```bash
python reproduce_jsc_stype.py --out results
```

The script uses deterministic parameter sweeps and fixed random seeds where random test cases are generated. It reproduces the numerical checks for:

1. balanced single-layer asymptotics;
2. maximum-norm and balanced-norm allocation crossover on Shishkin meshes;
3. exhaustive finite-budget optima;
4. random frozen balanced-objective validation;
5. Bakhvalov-S mesh crossover and exhaustive optima;
6. parameter-uniform maximum-norm pilot calculations;
7. Bakhvalov-S pure-layer coefficient and exhaustive-optimum checks.

The repository also contains a small deterministic Pareto diagnostic used during the allocation analysis; it is supplementary to the main manuscript results.

## Data availability

All numerical data required to support the reported tables and figures are included in this repository and can be regenerated from the supplied Python script.

## Software

The computations use NumPy, pandas, and Matplotlib. No proprietary software is required.
